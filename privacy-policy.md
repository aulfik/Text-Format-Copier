# Privacy Policy

## Overview
Text Format Copier is a browser extension that converts selected text into different formats such as Sentence case, lowercase, UPPERCASE, Capitalize Each Word, Slugify, and Snakify. It then copies the transformed result to the clipboard.

## What data we collect
This extension does not collect, store, or transmit personal data.

We do not:
- store your selected text
- save clipboard contents
- send text to third-party servers
- use analytics trackers
- require account creation

## How the extension works
The extension reads the text currently selected by the user in the active webpage. It transforms the text locally in the browser and copies the result to the clipboard.

The transformation is performed on the client side only and is not sent to any remote service.

## Permissions used
This extension requests the minimum required permissions:
- `contextMenus`: to display the right-click menu when text is selected
- `activeTab`: to access the current active webpage for the selected text
- `scripting`: to run a small script that copies the transformed text to the clipboard

## Data retention
No user data is stored by this extension. The text is processed temporarily in memory only while the action is being performed.

## Third-party services
This extension does not use third-party analytics, advertising services, or external APIs.

## Changes to this policy
If the extension changes in a way that affects privacy, this document will be updated accordingly.

## Contact
For questions or concerns, contact the project maintainer through the GitHub repository associated with this extension.
