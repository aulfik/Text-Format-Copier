# Release Notes

## v1.0.0 - Initial Release

### Added
- Right-click text conversion menu for selected text
- Sentence case transformation
- lowercase transformation
- UPPERCASE transformation
- Capitalize Each Word transformation
- tOGGLE CASE transformation
- Slugify transformation
- Snakify transformation
- Automatic clipboard copy after conversion
- Chrome Manifest V3 implementation
- Privacy policy document
- GitHub-ready project documentation

### Features
The extension allows users to highlight text on a webpage, right-click, and choose a conversion format from the context menu. The transformed result is copied to the clipboard automatically.

### Compatibility
- Chrome browser
- Manifest V3
- Supported on normal web pages using `http://`, `https://`, and `file://` URLs

### Notes
- Internal Chrome pages such as `chrome://` are not supported.
- This release is intended for initial public use and GitHub distribution.
